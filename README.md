# Codeva
منصة تعليم برمجة عربية ثابتة (Static) تعمل بدون خادم.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو ارفع المجلد على GitHub Pages / Netlify.

## الموجود
- 4 مسارات: HTML, CSS, JavaScript, Git & GitHub
- 24 درسًا مكتوبًا داخل `data.js`
- أمثلة كود وتمارين/مشاريع
- حفظ تقدم الطالب محليًا عبر localStorage
- بحث عن الكورسات
- فيديوهات عربية اختيارية مضمّنة من YouTube
- تصميم متجاوب للموبايل والكمبيوتر

## إضافة درس
أضف كائن درس جديد داخل مصفوفة `lessons` في `data.js`.
